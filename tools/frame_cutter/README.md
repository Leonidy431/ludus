# Нарезка кадров из видео — `cut_frames.py`

Скрипт сохраняет кадры из **локального** видеофайла в JPG или PNG:

- `--mode interval` — один кадр каждые N секунд (по умолчанию 5);
- `--mode scenes` — один кадр на каждую смену сцены (сравниваются гистограммы цвета соседних кадров).

Рядом с кадрами пишется `frames.json`: имя файла, секунда кадра, а в режиме `scenes` ещё и сила «скачка».

## Установка

```bash
pip install opencv-python-headless pytest
```

## Запуск

```bash
# каждые 5 секунд, JPG
python tools/frame_cutter/cut_frames.py video.mp4

# каждые 5 секунд, PNG, в свою папку
python tools/frame_cutter/cut_frames.py video.mp4 --format png -o frames/petka_ref

# все сцены (порог 0.35, не чаще раза в секунду)
python tools/frame_cutter/cut_frames.py video.mp4 --mode scenes

# сцен слишком много — поднять порог; слишком мало — опустить
python tools/frame_cutter/cut_frames.py video.mp4 --mode scenes --threshold 0.5 --min-gap 2
```

Имена файлов имеют вид `<видео>_00012_00h01m00.000s.jpg`: номер кадра и время.

## Тесты

```bash
python -m pytest tools/frame_cutter -q
```

Тесты собирают синтетическое видео из трёх цветных «сцен» по 4 секунды и проверяют оба режима.

## Права и что не кладём в репозиторий

- Скрипт **ничего не скачивает**. Видео нужно иметь на диске заранее и иметь право его обрабатывать.
- Скачивание с YouTube запрещено правилами YouTube, если у видео нет кнопки загрузки или разрешения автора. Поэтому загрузчика в скрипте нет.
- Кадры чужих игр («Петька» — собственность «Буки», S.K.I.F.; GAG — Gamos) служат только **локальным справочником по стилю**: свет, ракурс, композиция, темп гэгов.
  - В репозиторий и в игру они не идут.
  - Папка `frames/` внесена в `.gitignore`.
- В «Ржевском» переносим приёмы стиля, а не пиксели, персонажей или тексты. См. `docs/HLD_RZHEVSKY_VS_ORDER_2026-10-03.md`, таблицу прав.
