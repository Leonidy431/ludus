# SVG — собственная графика Ludus (исходники)

По указанию оператора (2026-09-29) новая векторная графика хранится в этой
папке, отдельно от кода игры.

| Папка | Что | Кол-во |
|---|---|---|
| `loc/` | локации (фоны сцен) | 63 |
| `npc/` | герои и NPC | 52 |
| `obj/` | предметы | 96 |
| `ui/` | элементы интерфейса | 1 |

Здесь лежат все 212 недостающих ассетов из `docs/STORYLINES_99_ASSET_MATRIX.md`:
209 из них нарисовали 10 художников, 3 дорисованы при сверке матрицы. У каждой
позиции в матрице статус `DRAWN`.

**Канон:**
- умбра и золото (`#1a0e04 #2a1808 #8a6a34 #c8a56a #e8c87a`), редкий красный
  `#c0392b`, синий только для воды;
- **без нимбов**;
- в каждом файле `role="img"`, русские `aria-label`, `<title>` и `<desc>` (ФОРМА → ДЕЙСТВИЕ → ЦЕЛЬ, номера миссий);
- без `<text>`, `<script>` и внешних ссылок;
- каждый файл проходит `xmllint --noout`.

**Происхождение:** всё нарисовано вручную. По правилу ТАБУ №0.15 перед рисованием
проверялся индекс 99 репо, пригодного сырья не нашлось. Святыни из сырья не
берутся никогда (ТАБУ №0.35 п. 6).

**Связь с игрой:** игра загружает графику из `public/ludus/art/` (там 91
файл, на который уже ссылается код). Когда сцена начнёт использовать файл
отсюда, его копируют в `public/ludus/art/` тем же коммитом. Исходник
остаётся здесь.
