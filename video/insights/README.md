# Видео: двенадцать инсайтов серии 1

**Запрос оператора (2026-10-02, дословно):** «Комит видео в отдельную папку и дай тут скачать».

`insights-ep1.mp4`: 1280×720, H.264 + AAC, 24 кадра/с, 75,7 с, около 4 МБ. Видео собирается одной командой и каждый раз выходит одинаковым.

**Что в видео:**
- **Начало:** титр «Атлас воды · серия 1 · инсайты».
- **12 инсайтов по 6,5 с**, в порядке `godot/data/pilot-insights.json`. Каждый показан так:
  - слева кадр-воспоминание с медленным наездом;
  - справа: номер и эпоха; что вызывает инсайт (место, порядок событий, время серии, глубина, находка, ступень помысла, неподвижность); строка рассказчика от третьего лица; какой закон мира инсайт объясняет (поле `explains`).
- **Финал:** титр «Каждая эпоха — читатель предыдущей».
- **Переходы:** 0,8 с наплывом.
- **Музыка:** начало сюиты «Наука. Любовь. Познание.» (`docs/music/cosmos/README.md`), в конце затухает 3 с.

**Честно:**
- Кадры 3 («Лента ночью») и 10 («Переписчик поднимает глаза») слабые: на них почти пустая плоскость. Они ждут перерендера.
- Реверберация в музыке приближённая: в шлеме реверберацию даёт движок.

## Как собрать заново

Нужно:
- Python 3 с `numpy` и `Pillow`;
- `ffmpeg` с кодерами `libx264` и `aac`;
- шрифты DejaVu Sans и Liberation Serif Italic (для кириллицы);
- для музыки — Godot 4.7.1.

```bash
# 1. кадры инсайтов (Blender 4.5, Cycles, seed 1375), если их нет
python scripts/prerender/render_insights.py --size 768 --samples 128
# 2. музыка под видео -> build/music/cosmos/suite-preview.wav
python3 scripts/music/cosmos_preview.py
# 3. видео -> video/insights/insights-ep1.mp4
python3 scripts/video/insights_reel.py
```

Без шага 2 видео собирается без звука.

**Как устроен `scripts/video/insights_reel.py`** (PEP 8):
1. **Кадр инсайта:** картинка 660×660 слева, за ней тот же кадр, размытый и притемнённый тушью.
2. **Наезд:** за 6,5 с увеличение 1,00 → 1,06.
3. **Текст:** шрифт DejaVu Sans; строка рассказчика — курсивом Liberation Serif.
4. **Подача кадров:** кадры не держатся в памяти разом, а передаются ffmpeg по одному. На каждом стыке последние 0,8 с одной сцены смешиваются с первыми 0,8 с следующей.
5. **Кодирование:** ffmpeg `libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart`, звук `aac 128k`.

## Почему видео лежит здесь, а не в `docs/`

Тест `scripts/raw_assets/tests/test_audio_pass.py` следит, чтобы в `docs/`, `godot/data/` и `public/ludus/data/` не было звуковых файлов (`.ogg`, `.wav`, `.mp3`…). Видео — это `.mp4` со своей дорожкой, и оператор попросил отдельную папку. В APK видео не идёт: оно вне `godot/`.
