# Концепты «Поручик Ржевский против Ордена» — процедурные (Python + Pillow)

Черновые концепт-листы по 10 промптам из `docs/RZHEVSKY_RESEARCH_2026-10-03.md`, раздел 6.7.

Картинки нарисованы кодом: это фигуры, палитра из отчёта, контур `#2B1B12` и цветные тени. Нейросеть не использовалась, GPU не было. Все персонажи наши собственные. Нет сходства ни с актёрами, ни с героями «Петьки» или других игр, нет религиозных символов.

Пересборка:

    python rzhevsky/concepts/draw_heroes.py
    python rzhevsky/concepts/draw_scenes.py
