В репозитории нет второй копии кода. Копия рядом с исходниками устареет с первым коммитом, а ворота, обходящие репозиторий, увидят каждый файл дважды (ТАБУ №0.35 п. 12). Поэтому полная папка собирается из единственного источника при каждой сборке.

**Конституция:** ФОРМА (вся сборка: её код и её слово) → ДЕЙСТВИЕ (собрать её в одном месте из одного источника, у каждого файла ссылка и хэш) → ЦЕЛЬ (кто собирает, проверяет или решает, находит каждую часть игры, и сборку можно повторить).
