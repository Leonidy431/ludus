# Ludus — погружение: сборка для Meta Quest 3 (Godot 4)

Проект шлема по ТАБУ №0.02. План по фазам — `docs/HLD_HEADSET_BUILD_2026-09-30.md`.

## Как поставить в шлем

### Вариант 1. APK (нативно, OpenXR)

1. В GitHub откройте **Actions → Godot headset build → последний зелёный прогон**. Внизу, в блоке **Artifacts**, скачайте `ludus-dive-quest-apk`. Внутри лежит `ludus-dive-quest.apk`.
2. Включите на Quest 3 **режим разработчика**: приложение Meta Horizon на телефоне → устройство → *Режим разработчика*.
3. Установите APK любым способом:
   - **Meta Quest Developer Hub** — перетащите APK в окно устройства;
   - **SideQuest** — кнопка «Install APK»;
   - **adb**: `adb install -r ludus-dive-quest.apk`.
4. В шлеме: **Библиотека → Неизвестные источники → Ludus — Погружение**.

APK подписан отладочным ключом из CI. Для шлема в режиме разработчика этого достаточно, для Meta Store — нет (фаза P7).

### Вариант 2. Браузер Quest (WebXR)

Откройте в браузере шлема **https://leonidy431.github.io/ludus/godot/** и нажмите «Войти в шлем». Эта версия появляется после мёржа в `main`.

## Управление

| Действие | Quest | Клавиатура |
|---|---|---|
| вперёд, назад, вбок | левый стик (по взгляду) | W S A D |
| вверх, вниз | правый стик вверх/вниз | R F |
| поворот | правый стик влево/вправо, шаг 30° | Q E, мышь с правой кнопкой |
| взять или рассмотреть | правый курок | Пробел |
| лампа | кнопка A | L |

## Что внутри

- Берег Иссык-Куля в разрезе: песок мелководья, шельф, затопленная терраса, свал, илистая равнина до 165 м.
- Термоклин на 50 м. Звук 1480 → 1435 м/с, температура 18 → 4,5 °C, свет по закону Бера — Ламберта.
- 99 объектов озера и 20 видов рыб, каждый в своём диапазоне глубин (`docs/ISSYK_KUL_FISH.md`).
- Добыча по правилам: взять, отпустить (эндемики), отдать в скрипторий, только смотреть.
- Задачи по поясам:
  - учебный курс: плавучесть, курс, медленное всплытие;
  - находки для писца;
  - свал и течение;
  - пересечение термоклина;
  - тишина глубины.
- Всплытие быстрее 10 м/мин — это «падение»: свет тускнеет до остановки безопасности. Смерти в игре нет.
- Сонар: эхо приходит с честной задержкой 2·дальность/c.

## Разработка

```bash
# Godot 4.7.1 и шаблоны экспорта
scripts/godot/ci_setup.sh all
cd godot
"$GODOT" --headless --path . --import
# Сверка GDScript-порта с JS-ядром (public/ludus/dive/dive-core.js)
node ../scripts/godot/make_fixture.js
"$GODOT" --headless --path . --script res://tests/run_tests.gd
# Кадры 3–120 м
xvfb-run -a "$GODOT" --path . --rendering-driver opengl3 -- --shots=/tmp/shots
# Web
"$GODOT" --headless --path . --export-release "Web" ../build/godot/web/index.html
```

**Правило одного источника.** Правила погружения живут в `public/ludus/dive/dive-core.js` (тесты `tests/dive-core.test.js`). `scripts/dive_core.gd` — порт этого файла. CI сверяет их по `tests/fixture.json`, поэтому правка правил идёт сначала в JS, потом в порт.
