# HLD — свой шаблон движка Godot для шлема: без лишних библиотек (2026-10-02)

Поручение оператора (дословно): «godot возможно как то в бинарник без лишних библиотек сконвертировать потом? поищи единственное решение из 888 по 48 параметрам из имеющихся»; «HLD такой и долг оператора запиши».

Решение и пул — `docs/decisions/ENGINE_BUILD_2026-10-02.md`. Долг оператора — `docs/OPERATOR_DEBT_2026-10-02.md`.

**Конституция:** ФОРМА (что шлем может нести: 76 МБ движка — три четверти APK) → ДЕЙСТВИЕ (движок собирается только из того, что игра вызывает, и меряется до слияния) → ЦЕЛЬ (место под голоса и хор учения без тяжелеющего APK и с читаемыми отчётами о падениях).

## Риски и ответы

1. **Урезка отрежет класс, нужный игре.**
   - Предубеждение: «тесты на стоковом движке поймают».
   - Контраргумент: тесты сейчас идут на стоковом редакторе, а урезанный только шаблон.
   - Почему: фаза E4 гоняет игру на той же урезке. Пока E4 не зелёная, `android` берёт стоковый шаблон.
2. **Сборка движка дорога по минутам CI.**
   - Предубеждение: «собирать в каждом прогоне».
   - Контраргумент: больше 45 минут задания `android`.
   - Почему: отдельное задание, кэш по хэшу; пересборка только при смене версии, профиля или флагов.
3. **Размер не известен до сборки.**
   - Предубеждение: «пообещай число».
   - Контраргумент: ТАБУ №0.011 п. 6.
   - Почему: число — из фазы E5.
