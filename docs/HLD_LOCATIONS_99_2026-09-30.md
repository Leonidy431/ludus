# HLD: 99 локаций по нашим сюжетам — основание (2026-09-30)

**Решение оператора (дословно):** «99 локаций добавь по 299 нашим сюжетам. бери предметы из 99 репо которые склонировали. келья вечернего дозора с предметами обители хорошо получилась. продолжай»; «задача для клауд мд правилом келья вечернего дозора с предметами обители табу и выше».

**Правила:** ТАБУ №0.013 (эталон локации — все девять пунктов), №0.07 (отбор: честный пул, пять критериев, детерминизм, разнообразие), №0.012 (реквизит: из 99 репо берётся всё, в сцену — только выход конвейера), №0.1/0.15 (конвейер 35 %, 12 вариаций, проверка глазами; урок D6), №0.011 (ревизор лимитов APK), №0.2/0.4/0.26/0.35 (святое не лут и не ключ, таинства — только свидетелем), №0.38 (три класса света, одна материальная логика), №0.39 (эзопов язык в интерфейсе), №0.03 (сквозной сюжет «Атлас воды»).

**Конституция:** ФОРМА — место с его светом и его настоящими вещами (келья, кузня, брод, шельф, ворота Сиса) → ДЕЙСТВИЕ — одна практика или одно действие в сердце места, из уже проверенных ядер игры → ЦЕЛЬ — вещи служат учению и не заслоняют его: святое на своём месте, без подписи, без ключа и без награды.

**Эта задача — основание:** какие 99 мест, для каких сюжетов, и каждое место задано по эталону кельи вечернего дозора так, чтобы следующие фазы только строили.

## Решения хора (предубеждение / контраргумент / почему)

1. **Число 299.** Предубеждение: «оператор сказал 299 — значит, сюжетов 299». Контраргумент: три списка по 99 дают 297, а всех сюжетных единиц 338. Почему: пишется настоящее число и его источник; ни добивать, ни урезать (ТАБУ №0.07 п. 2).
2. **Что такое место.** Предубеждение: «235 прокси локаций — это пул». Контраргумент: задники Москвы, Гоби, Каракумов и Сарая не связаны ни с одним нашим сюжетом, а многие сюжеты называют место без прокси (ворота Сиса, мастерская Крескесов). Почему: пул — 145 мест, где происходит хотя бы один наш сюжет; записи прокси — доказательство места, а не место.
3. **Уже построенное.** Предубеждение: «келья дозора, скрипторий, пристань, пояса погружения и тропа свидетеля тоже локации». Контраргумент: оператор просил добавить 99. Почему: построенное в пул не входит, его сюжеты считаются покрытыми (41 единица), новизна мест того же вида снижена на 3–4.
4. **Разнообразие.** Предубеждение: «брать по баллу, пусть будет пять берегов». Контраргумент: 99 одинаковых берегов не учат 99 разным делам. Почему: не больше двух мест одного вида, одно место — одна локация, минимум по семьям сюжетов; поэтому места «Киберслава» с правдой 5–6 вошли, а третий берег с баллом 42 — нет.
5. **Каждая живая миссия получает место.** Предубеждение: «пусть отбор решит баллом». Контраргумент: миссия без места в шлеме — текст без сцены. Почему: после минимумов отбор идёт по миссиям; все 92 миссии не на переписке покрыты новыми или построенными местами (тест).
6. **Таинства.** Предубеждение: «первая служба на берегу, камень покаяния, место гибели миссионеров 1339 г. — сильные сцены». Контраргумент: игра таинств не совершает (ТАБУ №0.26 п. 3, 8), латинские святые не выводятся (ТАБУ №0.2 п. 1). Почему: три кандидата отсеяны по безопасности, причина записана; брод оглашенных оставлен только как черта свидетеля.
7. **Сердце — из проверенных ядер.** Предубеждение: «у каждого места своя новая механика». Контраргумент: новая механика — новый код без проверки. Почему: 76 из 99 сердец — уже проверенные практики и действия (MissionCore 45, RuleCore 12, TrialCore 6, PassionCore 5, DiveCore 4, AtlasTraces 3, WitnessCore 1); 23 новых малых действия записаны со строкой Конституции и идут фазой L3.
8. **Предметы из 99 репо.** Предубеждение: «попаданий 130 из 171 — значит, предметы есть». Контраргумент: попадание — слово в пути файла; «barrel» находит ствол турели, «spade» — пики карт, «rope» — жгут теста. Почему: попадания — кандидаты склада реквизита (ТАБУ №0.012), в сцену — только через конвейер и проверку глазами; урок D6: для узнаваемой вещи сначала свой рисунок или прокси (163 из 178 вещей уже имеют прокси).
9. **Вызовы отрисовки.** Предубеждение: «карточка — одна плоскость, один вызов». Контраргумент: замер `.glb` показал по поверхности на слой SVG, до 85 на карточку. Почему: бюджет пишется двумя числами (как есть и после слияния), превышение — стоп-линия до фазы L2 (ТАБУ №0.011 п. 4).
10. **Имя наставника у сердца.** Предубеждение: «подсказка — это имя: “Прп. Максим Исповедник”». Контраргумент: церковный титул на ярлыке низводит святое до кнопки (ТАБУ №0.39 п. 3); тест поймал три такие подсказки (Максим, дважды Фотий), а в список слов добавлены сокращённые титулы («прп.», «свт.», «вмц.»), после чего попала бы и Макрина. Почему: подсказка говорит образом дела — «Максим, что не подписал указ», «Фотий-книжник у светильника», «Макрина с зерном на ладони»; титул звучит только в живой речи героя.
11. **Данные в APK уже сейчас.** Предубеждение: «не нести в шлем то, что ещё не построено». Контраргумент: строитель и тест читают данные в движке, иначе проверка героев и земли живёт только в Python. Почему: 228 КБ и 2,4 МБ кучи при чтении — измерено и в пределах; ни одна сцена данные пока не читает.
12. **Святыня в локации.** Предубеждение: «святыня — сердце святого места». Контраргумент: святое не ключ и не находка (ТАБУ №0.4 п. 1). Почему: у 9 локаций святыня стоит в своём слоте плоско или как утварь, без бирки, `noInteract`/`noLoot`, не больше одной; сердце места — всегда другое действие; лампада только там, где есть святыня (тест).
