# HLD: нарастающая кривая вау в пилоте (2026-10-03)

**Слова оператора (дословно):** «включи дизайнеров по смачности и эргономи и вау эффектам. должны по нарастающей постоянно вау эффекты».

**Трио дизайнеров:** смачность (что чувствуется в руке и в ухе), эргономика VR (где в поле зрения, на каком расстоянии, без укачивания), вау-эффекты (кривая нарастания). Проверяющие — хор (ТАБУ №0.37): катехизатор (святыня), водолаз-гидроакустик (физика воды), Аристотель-скептик (числа).

**Конституция:** ФОРМА (свет, вода, звук и руки игрока в шлеме) → ДЕЙСТВИЕ (каждый бит серии отвечает чуть сильнее прежнего, у хачкара мир стихает) → ЦЕЛЬ (игрок чувствует путь вглубь и к свету; тишина у святыни громче любого эффекта — Энтелехия IX.8).

## Кривая (бит: уровень)

`drop:1 water_rises:2 immersion:3 hands_on_stick:4 walls:4 thermocline:5 tether_jerk:6 bookmark:5↓ lure:7 price_rises:8 choice_echo:8 khachkar:0 (тишина) diary:9 mark_line:9 ascent:10 room_drains:10 prior_last:9↓ title:10`

- Два затишья перед ударом, оба с `why`: `bookmark` — выдох перед приманкой, `prior_last` — сухая тишина перед рассветом титра.
- Хачкар — уровень 0, эффекта нет вовсе, его секунды не идут в счёт паузы роста.
- Самая долгая пауза роста — 120 с (choice_echo 590 → diary 720 минус 80 с у хачкара; потолок — 180 с).

## Хор

- **Предубеждение:** «вау должно расти и у хачкара — это кульминация». **Контраргумент** (катехизатор): у святыни мир стихает (ТАБУ №0.4 п. 2, №0.015 п. 5); тишина после уровня 8 сама становится самым сильным событием. **Почему:** хачкар — уровень 0, эффект запрещён тестом.
- **Предубеждение:** «по нарастающей — значит без единого спада». **Контраргумент** (драматург): без выдоха удар не читается, рост превращается в шум. **Почему:** разрешено не больше двух затишьев, у каждого `why`, после каждого — новый пик.
- **Предубеждение:** «рывок троса сильнее, если повернуть мир на 30°». **Контраргумент** (эргономика): принудительный поворот камеры — главный источник укачивания в VR. **Почему:** рывок — свет, звук троса и обе руки; `moves_camera: false` проверяется тестом; поворот, если оставить, — только по явной настройке.
- **Предубеждение:** «вау = больше частиц». **Контраргумент** (Аристотель-скептик): на уровне 9 частиц меньше, чем на 10, но смысл (дневник, голоса сходятся) сильнее; вау меряется кривой событий, а не числом частиц. **Почему:** частицы ограничены 256 и 1 мс GPU, а рост задаёт смысл.
- **Предубеждение:** «мерцание 3,3 Гц — это меньше 3 вспышек на кадр». **Контраргумент** (скептик): период 0,3 с даёт 3,33 вспышки в секунду, выше черты фоточувствительности. **Почему:** полупериод 0,2 с (2,5 Гц), под reduced — плавный провал без тёмного кадра.

## Хуки для `pilot.gd` (интегрирует лид)

1. **`_enter(b)`** — в конце, после `match`:
   ```gdscript
   wow = WowCore.effect_at(t, reduced)  # {} у хачкара
   if not wow.is_empty(): _wow_start(wow)
   ```
2. **Новая `_wow_start(e)`** — разложить триаду в существующие эффекты: `effects.append({"k": "lamp"/"fog", ...})` из `e.visual`; звук: `synth.event_click/servo/take()` или `duck_db` из `e.sound`; руки: `Haptics.pulse(right_hand/left_hand, e.haptic.kind, reduced)` (пустой `kind` — ничего).
3. **`_effects()`, ветка `"flicker"`** — заменить квадратную волну 0,15 с:
   ```gdscript
   var base := room_light.light_energy if e.room else lamp.light_energy
   var v := WowCore.flicker_energy(base, t - float(e.from), float(e.until) - float(e.from), reduced)
   ```
   и присвоить `v` свету комнаты или лампе.
4. **`_jerk()`** — поворот только по явной настройке: `if reduced or not data.comfort.get("jerk_turn", false):` — ветка затемнения; в `pilot-1.json` `comfort.jerk_turn = false` (или `jerk_yaw_deg = 0`).
5. **`_enter(b)`, ветка `b.has("haptic")`** и `_detail()` с `p.haptic` — фоновые толчки, которые не вызвал игрок (рывок, бит), под reduced пропускать: `if reduced and b.id != "drop": pass` либо добавить `"jerk"` в `Haptics.AMBIENT` (правка `haptics.gd` + `test_haptics.gd`).
6. **`run_hub_tests.gd`** — рядом с `test_insights.gd`:
   ```gdscript
   load("res://tests/test_wow.gd").new().run(self)
   ```
