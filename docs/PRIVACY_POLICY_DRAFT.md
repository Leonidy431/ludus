# Ludus — политика приватности (черновик для Meta Store, Д-21)

*Черновик. Публикует и утверждает оператор (правообладатель). Технические утверждения ниже проверены кодом: `godot/scripts/pack_fetch.gd`, тест `godot/tests/test_pack_fetch.gd`, ТАБУ №0.26, №0.35 п. 21.*

**Что игра хранит.** Сохранения прохождения (выборы, атрибуты, журнал действий) лежат только на вашем шлеме, в папке приложения. Они удаляются вместе с приложением. Мы их не получаем.

**Что игра отправляет.** Ничего о вас. Игра не собирает имя, учётную запись, голос, биометрию, местоположение, контакты, рекламные идентификаторы. Аналитики и телеметрии нет.

**Что игра скачивает.** Когда есть сеть, игра может скачать дополнительные материалы — голоса, музыку, следующие серии — как файлы с GitHub Releases (`github.com/Leonidy431/ludus/releases`). Это обычный запрос файла. Как любой веб-сервер, GitHub видит IP-адрес устройства и технический заголовок движка (политика GitHub: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Подлинность каждого файла проверяется по контрольной сумме SHA-256, вшитой в игру. Без сети игра работает полностью, без дополнительных материалов.

**Подготовка к исповеди.** Листок подготовки ничего не сохраняет и никуда не отправляет. В шлеме поля для записи нет, голосовой ввод выключен. Игра таинств не совершает.

**Камеры шлема.** В режиме прозрачности (passthrough) комнату показывает система шлема. Кадры камер игре недоступны и не сохраняются.

**Дети.** Игра не собирает данных ни у кого, в том числе у детей.
