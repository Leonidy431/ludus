# HLD: ИИ-напарник «Клауд» — голос в гарнитуре оператора ROV (2026-10-03)

**Правило:** CLAUDE.md, ТАБУ №0.026. **Решение оператора (дословно):** «дай герою ИИ Клауд и озвучь голосом близким к кортана из Halo»; «это правило в клауд. мд выше и табу».

**Конституция:** ФОРМА (честный прибор с голосом: знает только то, что меряет DiveCore, и сохранение игры) → ДЕЙСТВИЕ (называет глубину, температуру, давление, предел подъёма, рывок троса, цену приманки; подсказывает ступенями; переводит строку дневника вместе с писцом; у хачкара молчит) → ЦЕЛЬ (герой учится различать: машина помогает видеть, а выбирать и молиться — человеку; признаки IV.4, VI.11 «как ты?», VIII.3).

## Кто он и чем отличается от рассказчика

- **Рассказчик** (`pilot-narration.json`) говорит о герое в третьем лице, субтитром внизу кадра (ТАБУ №0.020).
- **Клауд** говорит с героем в первом лице, на «ты», в гарнитуре и строкой на пульте. Он — прибор: телеметрия, журнал, сеть, перевод. Он не знает мыслей героя и не видит его выбора (в строке `stage:captive` нет и намёка на «я знаю, что ты решил»).
- **Грамматический род.** Имя «Клауд» мужское по форме, голос женский. Реплики написаны без глаголов прошедшего времени о себе («нашла / нашёл»), в настоящем времени. Хор: предубеждение — «надо выбрать род»; контраргумент (редактор языка) — любое решение спорит то с именем, то с голосом; почему — настоящее время снимает спор и звучит собраннее, как отчёт прибора.

## Голос (спецификация)

- **Тембр и манера:** тёплое женское меццо; ясная, быстрая, собранная дикция; спокойная ирония (2–3 реплики-характера на серию, не больше: «Паниковать — моя работа», «Я с физикой не спорю», «Одно из моих немногих преимуществ»).
- **Обработка «цифрового отблеска»:** лёгкий двухголосый хорус (18 и 26 мс, глубина 1,4–1,9 мс); три коротких «стеклянных» ранних отражения 9/17/26 мс с затуханием 0,16/0,10/0,06; полка высоких +3 дБ от 9 кГц («воздух»); тепло +2 дБ на 220 Гц, разборчивость +1,5 дБ на 3 кГц; громкость −16 LUFS, пик ≤ −1,5 dBTP (ТАБУ №0.4 п. 13). Тон ниже на ~1,5 полутона с сохранением формант (к меццо, без «замедленной плёнки»).
- **Не копия.** Близость к Кортане — только по тембру и манере, словами выше. Голос Jen Taylor не имитируется, не клонируется и не служит референсом для обучения; звуки, музыка, имя, образ и тексты Halo (Microsoft) не используются. Название Halo живёт только в документах разработки (ТАБУ №0.03 п. 7, №0.35 п. 21).
- **Черновой голос.** Открытый TTS, помечен «черновой голос» в данных (`draft_voice: true` у файла и у каждой строки), в OGG-комментарии и в манифесте. Синтетический голос за живой не выдаётся; субтитр есть всегда. Чистовой — живая актриса по договору и с согласием.

## Хуки для `pilot.gd` (интегрирует лид)

1. **Данные:** в `_ready()` — `companion = CompanionCore.load_data()`; поле `var companion := {}`, `var said_by_claud: Array[String] = []`, свой `AudioStreamPlayer` `claud_voice` (шина голоса, не музыки) и `Label3D` строки на пульте.
2. **Функция** `claud(event: String)` рядом с `narrate()`:
   ```gdscript
   func claud(event: String) -> void:
       var tag := beat_id + "/" + event
       if tag in said_by_claud:
           return
       var text := CompanionCore.line_for(beat_id, event, lang, companion)
       if text == "":
           return  # at the holy, and where nothing is written
       said_by_claud.append(tag)
       console_line.text = text  # + " · " + draft label while draft
       var x := CompanionCore.entry(companion, beat_id, event)
       var voice := CompanionCore.voice_path(companion, x, lang)
       if claud_voice and FileAccess.file_exists(voice):
           claud_voice.stream = AudioStreamOggVorbis.load_from_file(voice)
           claud_voice.play()
   ```
3. **Где звать:**
   - `_enter(b)` → `claud("enter")` после `narrate("beats", b.id)`; если у бита `message_ru` — `claud("message")`.
   - `_taboo()` при смене ступени → `claud("stage:" + state.stage)`.
   - `open_examine(e)` → `claud("look:" + e.id)` (есть `lure/look:Drams`; у хачкара строка пустая).
   - `_depth()` пересекает `DiveCore.THERMOCLINE_M` сверху → `claud("depth:50")`; через 20 с в слое — `claud("temp")`.
   - рывок троса `_jerk()` → `claud("telemetry")`; счётчик оборотов ≥ `DiveCore.KINK_TURNS` → `claud("tether:kink")`.
   - подъём: `DiveCore.ascent_rate(...)` превышен → `claud("ascent:fast")`; остановка → `claud("safety_stop")`.
   - дневник: первая строка сканера → `claud("translate")`; строка молитвы в дневнике → `claud("line:holy")` («тип не определён»).
   - `mark_line`/`room_drains` при показе знака → `claud("mark")`.
   - подсказки: держит взгляд без находки 20/40/60 с → `claud("hint:1")`, `"hint:2"`, `"hint:3"` (ступени ТАБУ №0.017; цена — строка в журнале, не очки).
   - тишина 30 с без событий → `claud("idle")` (по одному разу на бит).
4. **Святыня:** в бите `khachkar` строка Клауда гаснет вместе с пультом за 1,75 с, `claud_voice.stop()`; `line_for` всё равно вернёт "".
5. **Порядок с рассказчиком:** рассказчик первым; Клауд — через 0,8 с после конца его субтитра или если субтитра нет. Голос Клауда приглушает машинный синт на 6 дБ, но не трогает room tone.
6. **Регистрация теста** в `godot/tests/run_hub_tests.gd`, рядом с `test_insights.gd`:
   `load("res://tests/test_companion.gd").new().run(self)`

## Хор (несогласие сохранено, ТАБУ №0.37)

1. **Голос «как у Кортаны».** Предубеждение: «близость = взять сэмплы или клонировать». Контраргумент (редактор-скептик, юрист через Аристотеля): подражание конкретному живому голосу без согласия — правовой и этический риск, а клон — обман слушателя. Почему: берём только описание тембра и манеры; источник — открытая модель и фиксированная цепь фильтров.
2. **Открытый TTS сейчас.** Предубеждение: «черновик лучше тишины — значит, можно в релиз». Контраргумент (редактор-скептик): лицензия датасета irina неизвестна, lessac — под условиями Blizzard 2013. Почему: черновик только для прослушивания командой; в магазин — после юриста или живой записи.
3. **Машина и святое.** Предубеждение: «напарник должен утешать у святыни». Контраргумент (катехизатор, патролог): машина не молится и не судит (узлы 8, 86, 93); утешение у святыни — тишина. Почему: строка пуста, тест валит сборку, если нет.
4. **Решение героя.** Предубеждение: «подсказка в выборе — это помощь». Контраргумент (драматург, гейм-дизайнер Конституции): свобода — суть выбора между предательством и жертвой. Почему: Клауд называет цену («Это цена, а не подарок. Решение — твоё»), но слова «возьми / не бери / отдай» запрещены проверкой.
5. **Числа.** Предубеждение: «цифры в реплике — колорит». Контраргумент (гидроакустик-водолаз): ложная константа слышна сразу. Почему: каждое число в строке объявлено фактом и сверено с DiveCore; для голоса — `say_ru`/`say_en` словами.
6. **Имя.** Claude — марка Anthropic; оператор подтверждает имя до магазина (ТАБУ №0.026 п. 6). Риск записан.
7. **Длина.** Строки ≤ 120 знаков, но три голосовые дорожки длиннее 7 с (термоклин 9,7 с: числа словами). Предубеждение: «правило 7 с рассказчика». Контраргумент: Клауд — не рассказчик, он читает приборы, а их числа нельзя сократить. Почему: допускаем до 10 с; если оператор услышит затянутость — термоклин делится на две строки.
