# HLD: подмена при осмотре (Swap Rendering) — «очки героя» (2026-10-02)

**Поручение оператора (дословно):** «перерисуй графику. герой очки одевает там где графика идеальна. думай где Технология подмены (Swap Rendering)… отказ от честного 3D при детальном рассмотрении… Модальный переход (The Close-up Swap)… Машины Silicon Graphics… Ментальная склейка». Дальше по разделам: билборды, запечённый свет, фальшивые тени, depth cueing, палитры, FMV.

**Конституция:** ФОРМА (вещь мира как она есть: в мире грубый прокси, в руке и в очках — точная) → ДЕЙСТВИЕ (надеть очки и вглядеться: мир замирает, остаётся одна вещь) → ЦЕЛЬ (внимание к малому — начало различения; так писец читает строку, а оператор — ил).

## 2. Правила подмены

1. Подменяются только вещи из `pilot-1.json` → `examine`. **Святыня не подменяется:** у неё интерфейс уходит, крупного плана нет, «осмотр» не открывается (ТАБУ №0.4 п. 1–2). Проверка `PilotCore.check_examine`.
2. Мир на паузе: часы серии стоят, пока открыт крупный план; машинный звук проседает.
3. Пререндер детерминирован: тот же скрипт даёт тот же кадр; источник истины — код сцены пререндера, а не ручная правка картинки.
4. Вес: картинка 768² сжата ETC2 без мипмапов, около 0,3 МБ. Пять вещей — около 1,5 МБ из 20 МБ прорыва (ревизор меряет, ТАБУ №0.011).
5. Строка у крупного плана — голосом ремесла, без церковных слов (ТАБУ №0.39).

## 4. Хор: предубеждение / контраргумент / почему

1. **«Подмена — обман, честнее полное 3D».** Контраргумент: Quest 3S не потянет в реальном времени блики и мягкие тени, которые даёт офлайн-кадр. Обман был бы в том, чтобы выдать прокси за готовую модель; здесь же прокси честно помечен `lod: proxy`, а картинка — `prerender`. Почему: так поступала Pandora, и так глаз получает точность там, где смотрит.
2. **«Очки — лишний шаг».** Контраргумент: модальный переход должен иметь причину в мире, иначе это меню. Почему: диегетика (ТАБУ №0.017, класс 3 «аскеза интерфейса»).
3. **«Пусть и хачкар будет крупным планом — он самый красивый».** Контраргумент: святыня не предмет осмотра под лупой оценщика. Почему: ТАБУ №0.4 п. 1–2, №0.03 п. 4.
