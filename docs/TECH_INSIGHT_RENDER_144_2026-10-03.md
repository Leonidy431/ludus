## 3. Как воспроизвести

```sh
python3 scripts/prerender/insight_variants.py            # рецепт
/home/user/bpy-venv/bin/python scripts/prerender/render_insights.py \
    --variant-file godot/data/pilot-insight-variants.json \
    --all-variants --size 512 --samples 56 [--only id] [--force]
python3 scripts/video/insight_variant_sheets.py           # листы
python3 scripts/prerender/insight_variants.py --merge     # камера кадров
python3 scripts/story/insight_branches.py                 # ветки

python3 -m unittest scripts/tests/test_insight_branches.py
python3 scripts/video/insights_variants_reel.py           # два ролика
```

Один вариант: `--only ford_of_cold --variant 8 --force`. Без `--force` готовый кадр пропускается, поэтому прерванный прогон продолжается с места.

## 4. Как узел ветки входит в игру

1. Инсайт приходит по своему фактору (ТАБУ №0.021 п. 2). Вариант выбирают часы устройства игрока: двенадцать часов дня — двенадцать вариантов рецепта. Без случайности; часы не уходят в сеть.
2. Кадр варианта показывается в вуали инсайта, строка рассказчика — субтитром (ТАБУ №0.020).
3. След ветки: строка журнала `journal:<id>_vNN` и память одного героя `insight_hour.<id> = <час>`. Просмотр и пропуск не награждаются и не наказываются (ТАБУ №0.021 п. 3).
4. В сходящемся бите (`bridge_to` инсайта, `godot/data/pilot-1.json`) одна реплика вспоминает этот час; ответ игрока в диалоге может дать +1 к одному из семи атрибутов (никогда к Вере и к Хитрости). Все 12 веток инсайта сходятся в один бит — узкое горло: 144 ветки, 9 сходящихся битов.
5. У святыни (кайрак, id `khachkar`) инсайтов и веток нет.

## 5. Чего нет

- **Не в APK.** Кадры лежат в `build/insight_variants/` (вне `godot/`) и в zip до приёмки оператором. В шлем идёт только выбранный кадр и только после приёмки (ТАБУ №0.011, №0.018: тяжёлое — пакетом).
- В APK входят только два JSON-рецепта (`pilot-insight-variants.json`, `pilot-insight-branches.json`); их размер — §6.
- Логика выбора варианта по часам в `pilot.gd`/`InsightCore` ещё не написана: это следующая фаза (паритет — `docs/APK_PARITY.md`).
- Видео-нейросеть не запускалась: промты готовы (`status: ready_for_render`), ролики собраны из кадров Cycles.
- «Проверено в шлеме» говорит только оператор (ТАБУ №0.02 п. 4).
