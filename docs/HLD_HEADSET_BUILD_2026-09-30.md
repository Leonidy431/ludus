# HLD: сборка для шлема — Godot 4, сцена погружения первой

**Статус:** рабочий план, 2026-09-30.

**Решения оператора (дословно):**
- «Godot Engine 4 (MIT) скачай все репо что понадобятся внедряй в код»;
- «с погружения как и просил»;
- «пока не будет версии для загрузки в шлем не стоп. пиши HLD по фазам и го».

**Цель — две формы, которые можно запустить в Quest 3:**
1. **Web (WebXR).** Экспорт Godot для Web, открывается в браузере Quest по ссылке Pages. Самый быстрый путь проверки.
2. **APK для Quest.** Экспорт Godot для Android с OpenXR. Устанавливается через Meta Quest Developer Hub, SideQuest или `adb install`. Это и есть «версия для загрузки в шлем».

## Решения хора (предубеждение / контраргумент / почему)

| Решение | Предубеждение | Контраргумент | Почему так |
|---|---|---|---|
| Godot 4.7.1 (MIT), а не Needle или three.js | «веб-стек уже есть» | нативный APK для Quest, редактор и открытая лицензия | решение оператора; MIT снимает лицензионный риск ТАБУ №0.25 п. 4 |
| Правила погружения живут в чистом JS-ядре `dive-core.js`, а GDScript-порт сверяется с ним по общему контрольному файлу | «один язык проще» | правила уже проверены в node, а веб-версия игры тоже на JS | один источник истины, расхождение ловит CI |
| Рендерер Compatibility (GL) | «Forward+ красивее» | Quest — мобильный GPU, 72 Гц; Web-экспорт требует Compatibility | один рендерер для APK и Web |
| Web-экспорт без потоков | «потоки быстрее» | GitHub Pages не отдаёт заголовки COOP и COEP | без потоков работает на Pages и в Quest Browser |
| Сцена строится кодом, а `.tscn` минимальный | «сцены надо собирать в редакторе» | редактора в CI нет, код проверяется и сравнивается в diff | детерминизм и ревью |
| Сначала погружение, хаб потом | «хаб — вход в игру» | решение оператора: «с погружения» | погружение — самостоятельный режим с решениями |

## Честные границы

- Готовность на шлеме подтверждает только сам шлем (дайджест п. 6). CI доказывает сборку, а не ощущения.
- Отладочный APK подписан отладочным ключом. Для Meta Store нужен релизный ключ в GitHub Secrets.
- Глубины рыб, профиль берега и температурный разрез — игровые ориентиры (`docs/ISSYK_KUL_FISH.md`, п. 6).

**Предупреждение по репо оператора (скептик).** godot4-oceanfft считает волны compute-шейдером. В Web-сборке и на рендерере Compatibility он не работает, возможен только в нативном APK на рендерере Mobile, и цену по кадру на Quest 3 надо мерить. godot_voxel — C++-модуль, под Android его нужно собрать. hitbox-hurtbox относится к боевой механике и по ТАБУ №0.2 п. 4 против страстей не применяется: страсть побеждается трезвением, а не оружием. Он годится только для ветки «Рыцари» и только как референс.
