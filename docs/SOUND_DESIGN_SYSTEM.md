# Ludus Sound Design System — Beautiful Orchestral & Choir Audio

**Purpose:** Create immersive, theologically-rich soundscape for Ludus game  
**Aesthetic:** Orthodox liturgical music + modern ethereal orchestration + natural environmental audio  
**Scope:** 40+ music tracks, 100+ SFX, voice acting, dynamic audio mixing

---

## 1. Audio Design Philosophy

### 1.1 Sonic Identity

**Ludus = Sacred + Modern + Immersive**

- 🎼 **Orthodox liturgical foundation** (Gregorian chant, Byzantine chant traditions)
- 🎻 **Modern orchestral arrangement** (strings, woodwinds, harp)
- 🎙️ **Human voice** (choir, soloists, spoken word)
- 🌊 **Environmental sounds** (water, wind, space ambience)
- ✨ **Ethereal textures** (pads, reverb, spatial effects)

### 1.2 Audio Principles

1. **Theological depth** - Music reflects spiritual content
2. **Emotional resonance** - Sound shapes player feelings
3. **Spatial immersion** - 3D audio for VR (Quest 3)
4. **Accessibility** - Captions for dialogue, volume controls
5. **Cultural authenticity** - Orthodox traditions respected
6. **Modern production** - Professional quality, contemporary mixing

## 5. Audio Mixing & Mastering

### 5.1 Dynamic Audio Mixing

**Layered Audio System:**

```
LAYER 1: MUSIC
├─ Ambient layer (volume: 0-1.0)
├─ Character theme (volume: 0 when no NPC, 0.7 when NPC present)
├─ Moment theme (volume: 0-1.0, overlays main music)
└─ Choir/orchestral swells (volume: 0-1.0)

LAYER 2: DIALOGUE
├─ NPC voice (volume: 0.8-1.0)
├─ Player voice (volume: 0.7-0.9)
├─ Narration (volume: 0.7-0.8)
└─ Auto-ducks music by 40% when dialogue plays

LAYER 3: SFX
├─ Environmental (volume: 0.3-0.6)
├─ Character actions (volume: 0.4-0.7)
├─ UI sounds (volume: 0.5-0.7)
└─ Spatial positioning (L/R/Center/Up/Down in 3D)

LAYER 4: AMBIENCE
├─ Background texture (volume: 0.2-0.4)
├─ Reverb tail from previous sounds
└─ Space definition (cave echo, outdoor openness, etc.)
```

### 5.2 Dynamic Mixing Rules

**When dialogue starts:**
- Music fades down to 0.4 volume
- Environmental SFX reduce to 0.3
- Dialogue stands out clearly
- When dialogue ends, music fades back up (1.5s)

**When emotional moment occurs:**
- Music swells
- Dialogue pauses (if speaker is shocked)
- SFX minimal
- Moment theme takes center

**During combat/challenge:**
- Music tempo increases
- SFX more prominent
- Dialogue becomes sparse
- Tension builds

### 6.2 Voice Recording Specifications

**Recording Quality:**
- Microphone: Neumann U87 or equivalent (professional)
- Sample rate: 48 kHz, 24-bit
- Compression: Minimal during recording
- Room: Acoustically treated studio
- Processing: Gentle EQ, no distortion

**Dialogue Recording Checklist:**
- [ ] Each line recorded 2–3 times
- [ ] Different emotional takes
- [ ] Variations (whisper, normal, passionate)
- [ ] Breath/pause management
- [ ] Consistency with other recordings

**Editing & Post-Production:**
- Normalize to -3dB peak
- Remove clicks/pops
- Add subtle reverb (room character)
- Compression: -1dB @ 4:1 ratio
- Master to -23 LUFS (streaming standard)

## 8. Audio Integration

### 8.1 Web Implementation (webtypicon2)

**Web Audio API:**

```javascript
// Simple example
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// Load and play dialogue
const dialogueBuffer = await audioContext.decodeAudioData(dialogueArrayBuffer);
const source = audioContext.createBufferSource();
source.buffer = dialogueBuffer;
source.connect(audioContext.destination);
source.start(0);

// Spatial audio (using panner for simple stereo positioning)
const panner = audioContext.createPanner();
panner.setPosition(1, 0, 1);  // X, Y, Z position relative to listener
source.connect(panner);
panner.connect(audioContext.destination);

// Volume management
const gainNode = audioContext.createGain();
gainNode.gain.value = 0.7;
source.connect(gainNode);
gainNode.connect(audioContext.destination);
```

**Audio Files:**
- Format: MP3 (lossy, streaming) + OGG (fallback)
- Bitrate: 256 kbps (dialogue), 128 kbps (ambient)
- Size: Keep individual tracks < 5 MB

### 8.2 VR Implementation (Meta Quest 3)

**Wwise Integration:**

```cpp
// Pseudocode
AkPlayingID playDialogue = AK::SoundEngine::PostEvent(
  "Play_NPC_Dialogue_Sergius",
  gameObject.ID
);

// Position NPC in 3D space
AkTransform npcTransform;
npcTransform.Set(
  npcPosition,      // 3D position
  npcRotation       // Direction facing
);
AK::SoundEngine::SetObjectPosition(npcGameObject.ID, npcTransform);

// Player position for spatial audio
AkTransform playerTransform;
playerTransform.Set(playerPosition, playerRotation);
AK::SoundEngine::SetListenerPosition(playerTransform, 0);

// Volume automation based on game events
AkRtpc musicVolume;
musicVolume.value = 0.4;  // Reduce for dialogue
AK::SoundEngine::SetRTPCValue("MusicVolume", musicVolume.value);
```
