## 1. Архитектурный принцип (Demiurgic Causality)

```
ФОРМА (7 атрибутов) ──гейт──▶ ДЕЙСТВИЕ (выбор, ритуал, погружение) ──учение──▶ ЦЕЛЬ (врата, theoria)
      ▲                                   │
      └──────── детерминированный бонус (+1..+5 по глубине выбора, без случайности) ◀──┘
Противник = одна из 8 страстей → распознаётся по признаку (трезвение) → побеждается исихией → добродетель → ступень Лествицы
```

Сквозные инварианты для всех фаз:
- ровно 7 атрибутов; «Этос» и «резонанс» — производные метрики;
- святое не бывает врагом, лутом, оружием или множителем;
- нимба в игровой графике нет;
- звук — язык: колокол по уставу, пение а капелла, тишина со смыслом;
- логи не уничтожаются.

## 3. Решения, которые ждут оператора
1. **VR-движок.** Needle Engine бесплатен только для некоммерческого использования. Варианты: платная лицензия или переход на three.js/A-Frame.
2. **LiveOps-календарь.** «366 миссий по сабианским градусам» в `backlog` — это астрология, она противоречит правилу 23 хора. Предлагается заменить их Синаксарём и седмичным кругом.
3. **Раннер vm-batch для ludus.** Нужно зарегистрировать машину раннером репо ludus и задать переменную `LUDUS_RAW_RUNNER`.
4. **Фрагменты HLD.** Кто сливает `docs/hld-fragments/` обратно в HLD_VR и HLD_Roblox?

## 4. Контроль
- Каждый час: сравнение «до / после» (desktop, Quest 3, mobile) и коммит.
- Каждые 1,5 часа: OSINT-проход по 99 репо.
- Каждые 6 часов: аудит-хор (ТАБУ №0.6).
- Готовность подтверждается только выводом команд и скриншотами (ТАБУ №0.35 п.22).
