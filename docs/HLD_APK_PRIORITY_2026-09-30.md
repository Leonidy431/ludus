# HLD: сборка APK для шлема — приоритет, каждая задача дополняет APK

**Статус:** рабочий план, 2026-09-30. Правило — ТАБУ №0.01 в CLAUDE.md.

**Поручение оператора (дословно):** «Дополняй сборку apk шлема это приоритет и правило Клауд мд выше и табу».

**Цель.** APK для Quest 3 растёт с каждой задачей и ставится поверх прежнего. Из `main` его можно скачать одной ссылкой. Список того, что есть в вебе и ещё не перенесено в шлем, ведётся и сокращается.

## Решения хора (предубеждение / контраргумент / почему)

| Решение | Предубеждение | Контраргумент | Почему так |
|---|---|---|---|
| Ключ подписи — в секрете, а не в репозитории | «отладочный ключ не секрет, положим в репо» | кто угодно подписал бы им свой APK, и шлем поставил бы его поверх игры | ключ в секретах; пока секрета нет, сборка честно предупреждает |
| Первым переносится тропа свидетеля | «сначала механика: врата, страсти» | наборы сцен уже готовы и сверены хором, в них нет логики, которую нужно сверять с JS | быстрый и безопасный прирост APK; механика страстей и испытаний врат — следующими, с эталоном из JS |
| Сцены таинств только как свидетель | «дать игроку подойти ближе» | ТАБУ №0.26 п. 10: игра таинств не совершает, игрок стоит у черты | черта свидетеля — граница тропы; ни кнопки, ни награды, ни записи присутствия |
| Исон и колокол на тропе пока не звучат | «без пения пусто» | колокол только по уставу и календарю; неверный звон хуже тишины | room tone есть (не цифровой ноль); исон и колокол — отдельной фазой через `LudusTypikon` из D5 |

## Блокер для оператора (одна строка)

Постоянный ключ: создать секрет репозитория `LUDUS_DEBUG_KEYSTORE_B64` (Settings → Secrets and variables → Actions). Значение — вывод команды `keytool -genkeypair -keystore ludus.keystore -storepass android -keypass android -alias androiddebugkey -dname "CN=Ludus Debug,O=Ludus,C=KG" -keyalg RSA -keysize 2048 -validity 10000 && base64 -w0 ludus.keystore`. До этого каждый APK ставится только после удаления прежнего.
